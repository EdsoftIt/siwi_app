# SIWI AGENT
Repositório para download do agent siwi

Rodar a sonda ou cadastrar a maquina manualmente no admin da Siwi

Instalar o executavel do Agent

Colocar o arquivo config.yaml dentro da pasta "C:\Program Files\Siwi Agent\config"

Rodar o comando siwi init no cmd adminstrador para realizar as devidas configurações
